# Sabreza View International v0.3.12

The remote-access agreement now appears as a white A4-style document, with a dated heading and numbered sections. The consent controls remain separate from the document and require an explicit user choice.

- Document revision: 19 November 2026, version 1.1. This identifies the text revision, not a user signature or consent timestamp.
- Thirteen sections cover access permissions, connection duration, refusal and withdrawal, security, liability boundaries, operator obligations, user obligations, retention information and electronic acceptance.
- A print / save as PDF button uses A4 print styling and includes the complete agreement across pages.
- English, German and Turkish text; responsive reading layout on phones.
- Displayed copyright attribution now names only Beyza KARARTI.
- Consent-page footer translations now run after the footer is present.

This update does not grant consent automatically, enroll additional devices or widen technical access. Printing or scrolling alone is not acceptance. The operator must still provide its specific privacy information, including processing purposes, legal basis, recipients and retention details.

## Installation

Download the appropriate package and compare its SHA-256 with `SHA256SUMS.txt`. Version 0.3.12 keeps the International identity introduced in 0.3.11. Older installations from before 0.3.11 use a different identity; installing International does not transfer their pairing or consent. Existing 0.3.11 users can install the update over that version; this UI update does not automatically request consent again from already connected devices.

Windows is the primary desktop target. macOS packages are experimental. Linux does not support screen sharing. The signed Android ARM64 package is the phone client, not a phone-monitoring installer.
